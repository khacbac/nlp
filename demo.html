3 · LLM judge chấm hai lượt

Câu hỏi:
[Câu trả lời A] [Câu trả lời B]
So sánh, giải thích ngắn, rồi kết luận "[[A]]", "[[B]]" hoặc "[[C]]" (hoà).
Prompt rút gọn. Bản đầy đủ là prompt chấm theo cặp của MT-Bench (pair-v2), kèm đoạn văn.

Lượt 2 · A = Y, B = X
